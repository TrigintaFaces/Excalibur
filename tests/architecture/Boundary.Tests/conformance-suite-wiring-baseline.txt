# Conformance suite wiring baseline.

# One non-comment line per entry: a repository-relative path, forward slashes. Lines starting with #
# and blank lines are ignored. Inline comments are NOT supported: the whole trimmed line is the
# identity, so rationale lives on the # lines above each group.
#
# An entry is a test file declaring a type that derives a *ConformanceTestKit and never invokes
# ConformanceSuite_ShouldWireEveryArm. Such a suite runs only the arms someone remembered to wrap,
# and an arm nobody wrapped is indistinguishable in the results from an arm that passed.
#
# ConformanceSuiteWiresEveryArmShould fails if a NEW one appears that is not listed here, and fails
# if a listed one starts wiring the guard (remove it) or stops deriving a kit (remove it). The list
# is a one-directional ratchet: it may shrink, never grow.
#
# THE ENTRIES ARE NOT ONE POPULATION. Do not "fix" them as a batch -- the second group is exempt by
# design and adding a guard there would break the non-vacuity proofs it exists to provide.
#
