# MongoDB BSON representation baseline — a one-directional ratchet.
#
# Each line records a persisted document field whose CLR type does not determine a BSON encoding
# (Guid, DateTime, DateTimeOffset, decimal) and which carries no [BsonRepresentation] attribute,
# together with the representation it ACTUALLY persists as today.
#
# The entries are evidence, not exemptions. They exist so that MongoBsonRepresentationGuardShould can
# tell a known gap from a new one: a field listed here may not silently change shape, and a field that
# is not listed here and not annotated fails the build.
#
# Format:  <Namespace.Type>::<Property> = <BsonType>   # rationale
#
# To remove a line: annotate the property with [BsonRepresentation(...)]. That is the only way out.
# To add a line: state why the field cannot be annotated. Adding an entry is a reviewable act — it
# widens the set of storage contracts nothing enforces.
