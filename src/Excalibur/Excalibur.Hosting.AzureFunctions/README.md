# Excalibur.Hosting.AzureFunctions

Azure Functions hosting integration for the Excalibur framework

## Installation

```bash
dotnet add package Excalibur.Hosting.AzureFunctions
```

## Quick Start

```csharp
services.AddExcaliburAzureFunctionsServerless();
```
