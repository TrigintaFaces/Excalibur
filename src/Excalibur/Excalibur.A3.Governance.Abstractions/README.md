# Excalibur.A3.Governance.Abstractions

Interfaces, records, and enums for IAM governance capabilities: access reviews, separation of duties, role management, and provisioning workflows.

This package defines the contracts. For implementations (in-memory stores, background services, builders), use `Excalibur.A3.Governance`.
